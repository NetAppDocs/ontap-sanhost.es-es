Las utilidades para hosts Linux te ayudan a gestionar el almacenamiento ONTAP conectado a un host Linux. NetApp recomienda encarecidamente instalar las utilidades para hosts Linux, pero no es obligatorio. Las utilidades para hosts Linux mejoran la gestión y ayudan al soporte al cliente de NetApp a recopilar información sobre tu configuración.
