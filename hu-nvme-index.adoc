= Aprende sobre cómo configurar hosts ONTAP SAN con NVMe-oF
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puedes configurar los hosts SAN compatibles para que usen el protocolo NVMe over Fabrics (NVMe-oF) con ONTAP como destino de almacenamiento. NVMe-oF incluye NVMe over Fibre Channel (NVMe/FC) y NVMe over TCP (NVMe/TCP). Dependiendo de tu sistema operativo (SO) del host y la versión de ONTAP, configuras y validas el protocolo NVMe/FC o NVMe/TCP, o ambos, en el SO del host.
