= Infórmate sobre cómo configurar hosts SAN de ONTAP con FCP e iSCSI
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puedes configurar ciertos sistemas operativos (SO) de host SAN para FCP e iSCSI con ONTAP como destino. Si tu sistema operativo de host es compatible con el software SAN Host Utilities, primero instalas el paquete de utilidades de host correspondiente, que incluye el kit de herramientas SAN. Luego, para todos los tipos de sistemas operativos de host, configuras los ajustes de multivía para los LUN de ONTAP.
